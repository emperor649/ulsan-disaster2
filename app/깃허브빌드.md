# GitHub Actions로 APK 만들기

PC 없이 폰만으로 APK를 받을 수 있습니다.
`.github/workflows/build.yml`이 이미 들어 있어서, 파일만 올리면 자동으로 빌드됩니다.

---

## 1. GitHub 가입

https://github.com → Sign up
이메일과 비밀번호만 있으면 됩니다. 무료입니다.

---

## 2. 저장소 만들기

1. 우측 상단 `+` → **New repository**
2. Repository name: 아무거나 (예: `ulsan-disaster-alert`)
3. **Private 선택** ← 중요
4. `Create repository`

---

## 3. 파일 올리기

저장소 화면에서 **`uploading an existing file`** 링크 클릭
(또는 `Add file` → `Upload files`)

압축 푼 폴더 안의 **내용물 전부**를 올립니다.
폴더째로 올리지 말고, 안에 있는 것들을 올리세요.

```
올릴 것
  app/                    ← 폴더째
  gradle/                 ← 폴더째
  .github/                ← 폴더째 (숨김이라 안 보일 수 있음)
  build.gradle
  settings.gradle
  gradle.properties
  README.md

올리지 말 것
  local.properties        ← API 키. 절대 올리지 마세요
```

**폰에서는 `.github` 폴더가 안 보일 수 있습니다.**
숨김 파일 표시를 켜거나, 파일 관리자에서 이름을 확인하세요.
이 폴더가 없으면 빌드가 시작되지 않습니다.

올린 뒤 하단 `Commit changes` 버튼을 누르면 **자동으로 빌드가 시작됩니다.**

---

## 4. 빌드 확인

상단 **Actions** 탭으로 이동하세요.

| 표시 | 의미 |
|---|---|
| 🟡 노란 점 | 빌드 중 (5~10분) |
| ✅ 초록 체크 | 성공 |
| ❌ 빨간 X | 실패 |

---

## 5-A. 성공하면 — APK 받기

1. Actions 탭 → 완료된 항목 클릭
2. 맨 아래 **Artifacts** 섹션
3. **기상재난알림-apk** 클릭 → 다운로드 (zip)
4. 압축 풀면 `app-debug.apk`

### 폰에 설치
APK 파일을 탭하면 설치 안내가 뜹니다.
"출처를 알 수 없는 앱" 허용이 필요합니다.
→ 설정 → 보안 → 출처를 알 수 없는 앱 → 해당 브라우저/파일관리자 허용

---

## 5-B. 실패하면 — 오류 확인

1. Actions 탭 → 빨간 X 항목 클릭
2. **build** 클릭
3. 빨간색으로 표시된 단계 클릭 → 펼치면 로그가 나옵니다
4. `error:` 로 시작하는 줄을 찾아 그대로 복사

**그 내용을 저에게 주세요.** 파일명과 줄 번호가 함께 있으면 정확히 고칠 수 있습니다.

### 파일 수정하는 법 (폰에서도 가능)
1. 저장소에서 해당 파일 클릭
2. 우측 연필 아이콘 ✏️
3. 고친 뒤 `Commit changes`
4. 자동으로 다시 빌드됩니다

---

## 6. API 키 넣기 (나중에)

키 없이도 앱은 켜집니다. 실시간 기능만 비활성입니다.
키를 넣으려면:

1. 저장소 → **Settings** 탭
2. 좌측 `Secrets and variables` → **Actions**
3. **New repository secret** 버튼
4. 아래 5개를 하나씩 등록

| Name | 값 |
|---|---|
| `KMA_SERVICE_KEY` | data.go.kr 인증키 (Encoding) |
| `TIDE_SERVICE_KEY` | data.go.kr 인증키 (위와 동일) |
| `KMA_APIHUB_KEY` | apihub.kma.go.kr 인증키 |
| `DISASTER_SERVICE_KEY` | safetydata.go.kr 인증키 |
| `FLOOD_SERVICE_KEY` | hrfco.go.kr 인증키 |

등록 후 Actions 탭 → 우측 **Re-run all jobs**를 누르면 키가 포함된 APK가 만들어집니다.

**Secrets는 저장 후 다시 볼 수 없습니다.** 키는 따로 보관해 두세요.

---

## 주의사항

**`local.properties`를 올리지 마세요.**
Private 저장소라도 마찬가지입니다. `.gitignore`에 넣어뒀지만,
웹에서 직접 업로드하면 무시될 수 있습니다.

**무료 한도**
Private 저장소는 월 2,000분입니다.
한 번 빌드에 5~10분이니 넉넉합니다. Public으로 하면 무제한이지만,
공개되므로 권하지 않습니다.

## 한계

첫 빌드는 오류가 날 가능성이 높습니다.

몇 번 왔다갔다 할 각오를 하시고, 오류 메시지는 그대로 주세요.
